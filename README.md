# Pain Study Room｜疼痛專科互動學習室

**公開網站：** https://tad820423ntu.github.io/pain_learning/

繁體中文疼痛醫學分段學習網站。新首頁可先選 CRPS、PHN 或 Pain neurobiology，再依「① 認識概念 → ② 理解機轉 → ③ 臨床連結 → ④ 自我整理」逐步學習；其他 23 項主題目前為「規劃中」。

## 已開放

- [CRPS｜12 單元](https://tad820423ntu.github.io/pain_learning/#/topic/crps)：6 個互動 Pathophysiology 節點
- [PHN｜13 單元](https://tad820423ntu.github.io/pain_learning/#/topic/phn)：6 個互動 Pathophysiology 節點
- [Pain neurobiology｜4 單元](https://tad820423ntu.github.io/pain_learning/#/topic/basics)：共同機轉入門

主題首頁支援搜尋和分類。桌機四個學習步驟等寬排成同一列，手機 2×2。閱讀進度與個人筆記僅存在當前瀏覽器 localStorage，沒有帳號與跨裝置同步。

## 一句話製作新章

在 ChatGPT 說 **「幫我做新的一章」**，會依 [完整工作流](WORKFLOW.md) 完成「新增 → 醫學查證 → 跨章統整 → 網站測試 → GitHub 更新」。

品質與版控檔案： [QA 報告](QA_REPORT.md)、[QA 結果](qa-results.json)、[內容狀態](content-manifest.json)、[更新紀錄](CHANGELOG.md)。

GitHub Pages 從 main 分支根目錄部署。不應在網站中公開病人資料、私人 Notion、未授權教科書內容或 API 密鑰。

**目前是公開試讀版，不是已完成全篇臨床專家審閱的醫學教材。** 重要數字完成部分交叉核對，但全部藥物劑量、臺灣核准適應症與介入技術仍需逐項審核。網站不取代醫師臨床判斷。
